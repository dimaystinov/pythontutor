Name:
Сколько дорог у каждой станции?

Statement:
<p>В первой строке записаны n и m — число вершин и рёбер (1 ≤ n ≤ 30). Далее идут m пар номеров вершин от 1 до n. Граф неориентированный, без петель и повторных рёбер. Выведите для каждой вершины по порядку число выходящих из неё рёбер.</p>

Test:
1 0

Answer:
0

Test:
4 2
1 2
2 3

Answer:
1 2 1 0

Test:
5 4
2 3
3 4
4 2
1 5

Answer:
1 2 2 2 1

Test:
4 0

Answer:
0 0 0 0
