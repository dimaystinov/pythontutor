# LocalSpeech как отдельный компонент

Контракт интеграции: https://github.com/dimaystinov/local-speech/blob/main/docs/integration.md

PythonTutor использует `create`, `start({input:"pcm"})`, последовательные `write` пакетами не длиннее секунды, `stop` и `dispose`. Частота PCM — 16000 Гц. В текст попадают только `final.rawText`, дедупликация — по sessionId и segmentId. Старая ветка Whisper и серверное распознавание исключены из помощника. Русский пакет 0.3.0 установлен отдельно; смешанное RU/EN распознавание не заявляется.

## Публикация совместимого обновления SDK

1. Проверить новый SDK на контракт API 1, браузере и packaged WebView. Версия приложения не меняется, если контракт совместим.
2. Разместить весь runtime, worker, WASM, worklet, evidence и русские модели в `static/local-speech/X.Y.Z/`. Никогда не заменять файлы уже опубликованной версии.
3. В этой же папке опубликовать `pythontutor-manifest.json`: version, apiVersion: 1, base: `https://dimaystinov.github.io/pythontutor/static/local-speech/X.Y.Z/`, files: [{path, bytes, sha256}]. Каждый исполняемый файл и модель должны быть в манифесте; сумма размеров ограничена 500 МБ. Не включать host-маркеры installed и .pythontutor-manifest.json.
4. После публикации всех файлов добавить {version: "X.Y.Z", apiVersion: 1} в `tutorial/static/pwa/local-speech-catalog.json` и опубликовать каталог на Pages. Для приложения каталог читается с фиксированного HTTPS-адреса, независимо от встроенной версии сайта.
5. Проверить установку, реальную расшифровку, отмену загрузки и возврат к прежней версии. Непроверенные/несовместимые версии в каталог не включать.

## Хранение

В приложении — отдельные папки speech/X.Y.Z и атомарно заменяемый указатель active. В браузере — версионные URL в Cache Storage и указатель в localStorage. Переключение происходит только после проверки всех размеров и SHA-256. Прежняя версия остаётся доступной. Удаление компонента в настройках удаляет все его скачанные версии, не меняя учебный прогресс.

Сейчас опубликован только совместимый пакет 0.3.0. Выбор новых версий появится после их проверки и добавления в каталог; произвольные GitHub-теги не устанавливаются автоматически.
