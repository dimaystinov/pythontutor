# Приложение PythonTutor

Установщик для Windows x64 и macOS (Apple Silicon и Intel) скачивает текущий учебник из ветки gh-pages и официальный OpenCode CLI из GitHub Releases. Python, Node.js и ручная распаковка пользователю не нужны.

Основная установка: учебник и CLI. Флажок «Qwen 7B и голосовой ввод» дополнительно скачивает все четыре пакета релиза v1.1.0, проверяет каждый файл по SHA-256 и размещает модели рядом с локальным учебником. Загрузки возобновляются через HTTP Range; интерфейс показывает этап и прогресс. Для локального Qwen по-прежнему нужны WebGPU и достаточная память GPU.

После установки открывается http://127.0.0.1:8043/pythontutor/. Помощник подключается к CLI автоматически. На GitHub Pages выберите OpenCode CLI и вставьте код подключения из окна приложения. Браузер может запросить доступ к локальной сети. Ни ключ провайдера, ни код подключения в репозиторий не записываются. Код подключения в браузере хранится лишь в открытой вкладке.

OpenCode CLI не делает облачную модель офлайн. Доступность бесплатных моделей, лимиты и необходимость авторизации определяет OpenCode. При отсутствии доступа приложение сообщает об ошибке; платные модели автоматически не выбираются. Реальный ответ от провайдера необходимо проверить на конкретной сети.

Фоновый процесс доступен только на loopback. API разрешает только чат с фиксированным списком моделей, требует Origin и код подключения. OpenCode запускается в отдельной пустой папке, без сторонних плагинов, с запретом всех инструментов. Общий сервер OpenCode, терминал и управление файлами не выставляются браузеру.

Автозапуск включается при установке: HKCU Run на Windows, пользовательский LaunchAgent на macOS. Отключение: снимите флажок и выполните обновление. Администратор не требуется. Обновление запускается кнопкой «Установить / обновить». Обновление программы не очищает браузерный прогресс. Прогресс локального адреса и GitHub Pages раздельный — перенесите его штатным экспортом/импортом при необходимости.

Сборка установщиков: workflow Desktop installers, три ОС/архитектуры, PyInstaller. Результаты публикуются как предварительный релиз desktop-v1.2.0. Подпись Apple/Windows пока не настроена; проверка нативного запуска выполняется в CI, полный ручной тест установщика на каждой ОС пока не заявляется.

Для разработки: python desktop/installer.py. Исходный запуск не регистрирует автозагрузку. Тесты: python -m unittest discover -s desktop -p 'test_*.py'.
