# PythonTutor Browser Edition v1.0.0

Учебник работает на GitHub Pages без серверной части и регистрации.

- 15 уроков, 134 задачи и 1302 теста.
- 8 заданий OpenCV с 24 проверками изображений.
- Python/Pyodide, NumPy, Pillow и OpenCV выполняются в браузере ученика.
- Пошаговый визуализатор, две раскрываемые подсказки, иллюстрации и разборы после решения.
- Локальные Qwen, голосовой ввод Whisper и озвучивание средствами устройства.
- Прогресс в IndexedDB, черновики и история диалогов в localStorage; экспорт и восстановление резервной копии.
- PWA: установка приложения и загрузка курса для работы без интернета.

Первый запуск Python и загрузка моделей требуют сети. Для локального ИИ необходим совместимый WebGPU и достаточная память. Веса моделей загружаются отдельно от курса. Очистка данных браузера удаляет локальные данные: используйте резервные копии.

Сервер аккаунтов и кабинет преподавателя не требуются и не развёртываются на Pages. Исходники прежнего Django-режима сохранены; Django используется для сборки статического учебника. Скрытых серверных тестов нет: клиентская проверка предназначена для самостоятельного обучения, а не защищённых экзаменов.

Учебные материалы сохраняют CC BY-NC-SA 3.0, код исходного проекта — MIT; подробности и авторство в docs/PROVENANCE.md.

## Проверено

142 задачи: 1326 тестов в настоящем браузерном Python, 0 ошибок. Проверены 304 страницы и внутренние ссылки. Прогресс и черновик сохраняются после перезагрузки; решение проверено при остановленном HTTP-сервере после загрузки PWA.
