# PythonTutor 1.1.0

Локальный учебник: 134 задачи Python, 14 задач OpenCV/HSV, уроки, тесты, рисунки, подсказки и визуализатор. Решения проверяются в браузере.

- Помощник Qwen Coder 7B получает условие текущей задачи и код ученика. Слабые модели удалены после сравнительной проверки.
- Модель и голосовой ввод доступны отдельными пакетами GitHub. Скачайте пакеты по кнопке в помощнике и выберите их вместе — распаковка вручную не нужна.
- Сброс прогресса очищает отметки, код и переписку, сохраняя курс и модели для следующего ученика. Проверен запуск задачи после сброса с выключенным сервером.
- Сохранены оригинальные цвета статусов задач, змейки в тестах и оформление результата.

## Файлы

`pythontutor-pages-v1.1.0.zip` — готовый статический сайт; размещается по пути `/pythontutor/` на HTTP localhost или HTTPS. Двойной клик по HTML не заменяет HTTP-сервер.

`pythontutor-source-v1.1.0.zip` — исходники и инструкции сборки.

`qwen7b-part-1.tar`, `qwen7b-part-2.tar`, `qwen7b-part-3.tar` — три части одной модели, нужны все.

`whisper-tiny-part-1.tar` — локальный голосовой ввод.

Для 7B необходим WebGPU с shader-f16 и примерно 5,1 ГБ доступной памяти GPU плюс запас. Русский голос для озвучки ответов должен быть установлен в ОС. Модель может ошибаться; ответы не заменяют проверку решения тестами.
