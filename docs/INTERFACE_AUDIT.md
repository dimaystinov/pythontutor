# Проверка интерфейса и начальных задач — 27.09.2026

## Исправления

1. В открытом помощнике задание уходило во вторую строку CSS Grid под меню. Причина: querySelector с `#visualizer,#image-task,.main` выбирал `.main` первым по порядку DOM; статус Python вставлялся перед всей колонкой и становился третьим элементом сетки. Теперь статус вставляется внутрь задания. Регрессионный тест сначала воспроизвёл ошибку, затем прошёл. В браузере подтверждены ровно две колонки и видимый заголовок задачи.
2. Обычный запуск Python без эталонного ответа падал: JavaScript null превращался в JsNull, не Python None. Сравнение теперь выполняется только для строкового эталона. Проверены обычный запуск, пустой вывод, правильный/неправильный результат, исключение, трассировка, лимиты и восстановление.
3. Для первых пяти задач добавлены начальные программы и примеры на изученных конструкциях. Заготовка используется только при отсутствии сохранённого серверного решения; локальный непустой черновик имеет приоритет. Эталонные разборы первых пяти задач также ограничены input/int/print, переменными, арифметикой и соединением строк. Старый QA-код с sum заменён в сетевом и локальном черновиках первой задачи.
4. Ссылка «Задачи» на странице задачи теперь ведёт к списку задач урока, а не к несуществующему якорю текущей страницы.
5. Обновлены инструкции локальному и облачному помощникам об уровне первых уроков. Соблюдение инструкций моделью не гарантируется.
