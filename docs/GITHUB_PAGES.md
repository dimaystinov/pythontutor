# Статический учебник

Рабочий сайт: https://dimaystinov.github.io/pythontutor/

На хостинге нужны только статические файлы: Python, проверка, изображения и локальный ИИ работают у ученика. Django нужен только сборщику и в опубликованный сайт не входит.

## Сборка

Установите зависимости из requirements.lock в отдельное Python-окружение и выполните:

```sh
python scripts/build_pages.py --base /pythontutor/
```

Результат: `dist/pages/`. Для корня собственного домена используйте `--base /`.
Загрузите содержимое каталога на статический HTTPS-хостинг. Для GitHub Pages используется ветка `gh-pages`, каталог `/ (root)`.

## Данные ученика

Решения и прогресс хранятся в IndexedDB, черновики, настройки и диалоги — в localStorage. Аккаунты, API-ключи и сервер не нужны. Раздел «Мой прогресс» позволяет скачать резервную копию и восстановить её на другом устройстве. Данные разных доменов браузер разделяет; перенос с localhost делается резервной копией.

Кнопка «Скачать для работы без интернета» сохраняет полный курс и среду Python в Cache Storage. Qwen/Whisper загружаются при первом использовании и имеют собственный кэш. Доступность локального ИИ зависит от WebGPU и памяти устройства; задачи можно решать без ИИ.

Очистка данных сайта удаляет прогресс и загрузки. Браузер может освободить хранилище при нехватке места. Резервная копия нужна для долговременного хранения.
