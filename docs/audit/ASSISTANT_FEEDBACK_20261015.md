# Помощь с ошибками — 15 октября 2026

Кнопка «Проверь мой код» использует последний результат браузерного Python без загрузки модели. Поддержаны типичные исключения Python, лимиты, ошибки изображений, неверный ответ, успешный одиночный запуск и проверка всего набора тестов.

Проверяются доступ к коду и совпадение с запущенной версией. При отсутствии запуска помощник предлагает выполнить программу. Диагностика хранится в памяти страницы; сброс прогресса делает её недоступной. В свободный диалог передаётся только результат для совпадающего кода при включённом доступе к нему.

Проверено в браузере: пустой print() в задаче о треугольнике даёт первый непройденный тест; print(missing) даёт объяснение NameError и строку 1. Node-тесты покрывают устаревший код, отключённый доступ, 12 типов исключений, неверный ответ, ограничения и результаты worker.

Это объяснение результата запуска, не полноценный статический анализ: успешный одиночный запуск не считается доказательством правильности.
