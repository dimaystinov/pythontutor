# Сравнение с pythontutor.ru/old/

Дата: 27 сентября 2026. Эталон выбран пользователем: именно старый курс `/old/`.
Сравнивались живые страницы оригинала и локальная установка в браузере.

| Область | Исправлено и проверено |
|---|---|
| Главная | Белая страница, двухколоночная композиция, заголовок, подзаголовок, 11 основных разделов, демонстрационное видео |
| Навигация | Rubik One, подписи, цвета ссылок, высота панели и блок пользователя |
| Уроки | Порядок разделов, компактное белое меню, размеры текста, заголовки, сворачивание меню |
| Задачи | Условие, подсказка input/print, кнопка проверки, таблица тестов и статусы |
| Визуализатор | Оригинальный CSS совпадает с исходным; списки, связи, dict/set/tuple, рекурсивные фреймы и стрелки проверены реальным кодом |
| Переполнение графа | Результат помещён в свою колонку с внутренней прокруткой; страница не расширяется |
| Медиа | Локальные оригинальные demo_debug_720p.mp4 и shoelace.gif; шрифт и остальные зависимости локальны |
| Формы | Вход и регистрация приведены к старому оформлению, работают с локальными пользователями |
| OpenCV | Цветное исходное изображение и реальный PNG-результат, скачивание, успешная проверка |
| База знаний | Стиль учебника; доступ только после собственной успешной сдачи |

Функциональные отличия сохранены намеренно: современный изолированный Python,
самостоятельная регистрация, новые OpenCV и разборы, дополнительные архивные
уроки. Рекламные блоки, социальные трекеры, внешняя авторизация и почтовая
инфраструктура исходного сервиса не воспроизводятся. Исправлены ошибки
оригинального старого визуализатора, связанные с современным Python.

Это проверка основных экранов и сценариев, не автоматическое попиксельное
доказательство равенства каждой страницы во всех браузерах и разрешениях.
Производственные скрытые тесты и закрытые пользовательские данные не копировались.
