## Ограничения качества

Даже 7B ошибается. В дополнительном техническом тесте вопроса про `3*5//2` она неверно обобщила поведение деления целых чисел и предложила обязательно переводить операнд в float. Это неверно для `/` в Python 3. Поэтому успешный запуск и доступ к контексту не означают безошибочную педагогическую помощь. Не обещать, что модель всегда даёт правильную подсказку.

## Распространение

Пакеты собираются GitHub Actions по закреплённым upstream-версиям и перед загрузкой проверяются по SHA-256. Пользователь скачивает только файлы GitHub Release. Из-за CORS GitHub требуется один выбор скачанных пакетов в файловом диалоге; полностью автоматическое межсайтовое `fetch()` не используется.
