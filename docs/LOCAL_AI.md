# Локальный помощник и выбор модели

Проверено 27.09.2026. Для обучения Python выбрана **Qwen2.5-Coder-1.5B-Instruct**, браузерная сборка MLC q4f16. Семейство Coder обучалось генерации, анализу и исправлению программ; это более подходящая специализация, чем общий чат. Модель не ограничена только Python.

| Выбор в приложении | Загрузка, ориентир | Память GPU по каталогу WebLLM (контекст 4096) | Назначение |
|---|---:|---:|---|
| Qwen2.5-Coder 0.5B Instruct q4f16 | ~0,4 ГБ | 945 МБ | Минимальная модель, качество объяснений ограничено |
| **Qwen2.5-Coder 1.5B Instruct q4f16** | ~1 ГБ | 1630 МБ | Компактный вариант по умолчанию для учебного Python |
| Qwen2.5-Coder 7B Instruct q4f16 | ~4,5 ГБ | 5107 МБ | Для мощного компьютера; больше затрат памяти и времени |
| Qwen3 1.7B q4f16 | ~1,1 ГБ | 2037 МБ | Универсальный диалог как альтернатива Coder |

Память из конфигурации WebLLM — оценка, не гарантия запуска; нужен запас для браузера, курса и изображения. Наличие WebGPU и shader-f16 проверяется перед загрузкой. Если устройство не подходит, приложение сообщает это и не переключается скрытно на облако. Количественный сравнительный бенчмарк всех четырёх моделей не проводился.

Практическая проверка: Qwen3 0.6B (пробный кандидат, не включён в окончательный список) повторила одну и ту же фразу при просьбе объяснить input(). Qwen Coder 1.5B верно назвала причину TypeError при сложении строки и числа и IndexError при обращении к индексу 3 списка длины 3; на этих двух вопросах соблюла просьбу не выдавать программу. В третьем тесте, где код считывался из редактора, модель верно определила ошибку, но выдала готовое решение вопреки инструкции. Поэтому до принятия задачи интерфейс дополнительно убирает fenced-блоки кода ; жёсткое ограничение двумя предложениями снято для естественного диалога; семантические спойлеры это не исключает. Это два примера, а не гарантия качества на всём курсе. 0.5B и универсальная 1.7B пока не прошли такую же проверку качества.

Первый выбор/загрузка модели требует интернета: веса скачиваются напрямую с Hugging Face, библиотека модели — с GitHub MLC. Библиотеки WebLLM 0.2.85 и Transformers.js 3.8.1 находятся на нашем сайте и входят в офлайн-пакет. WebLLM сохраняет веса, конфигурацию, токенизатор и WASM в браузерный CacheStorage. Вопрос, материал и актуальный код обрабатываются в отдельном Web Worker, без API-ключа и без отправки на сервер. История локальна и отделена по профилю и задаче. Изображения эти текстовые модели не принимают.

До успешной проверки системная инструкция просит давать подсказки, а после — улучшения. Это педагогическое поведение, не защита от получения ответа: ученик контролирует весь клиент. Разборы и тесты также скачаны на устройство и могут быть просмотрены через инструменты разработчика.

Голос: Whisper tiny (мультиязычный, q8) запускается через Transformers.js/ONNX Runtime WASM. Кнопка «Скачать голосовой ввод» подготавливает модель. Микрофон используется только после явного действия. Аудио ресемплируется в 16 кГц локальным AudioWorklet. Озвучка выбирает только русский голос с `localService=true`; при отсутствии установленного русского голоса показывается сообщение. Облачного резервного распознавания/озвучки в локальном режиме нет.

Gemini Flash — облачный API и не удовлетворяет требованию полностью автономного PWA. Gemini Nano доступна через встроенный ИИ некоторых версий Chrome, что ограничивает переносимость. Большие Qwen3-Coder/Next предназначены для существенно более тяжёлых конфигураций; малое число активных параметров MoE не означает малый объём всех весов. Qwen2.5-Coder 3B не включена: её upstream-лицензия `qwen-research` отличается от Apache 2.0 у выбранных 0.5/1.5/7B.

## Практическая проверка Coder 7B — 27.09.2026

Проверена реальная сборка Qwen2.5-Coder-7B-Instruct q4f16 в помощнике через WebGPU. Первичная загрузка весов показала около 4,1 ГБ и заняла примерно две минуты, после чего модель успешно инициализировалась. Это результат на текущем компьютере и соединении, не оценка для всех устройств.

- Текущий код редактора `n=input();print(n+1)`: верно объяснила несовместимость строки и числа, без готовой программы.
- При отдельном вопросе про `rows = [[0] * 3] * 3` с включённым контекстом редактора ошибочно повторила ответ про TypeError. Это провал переключения контекста.
- После отключения «Помощник видит мой код» верно объяснила общую ссылку на один подсписок.
- Для изменяемого аргумента `items=[]` верно объяснила однократное создание списка при определении функции и повторное использование между вызовами.

Последние два ответа получены при остановленном контейнере Django; сервер после проверки запущен и healthy. Интернет физически не отключался. Ответы проверялись в интерфейсе с действовавшим на момент теста ограничением до двух предложений до принятия задачи; это не оценка необработанного вывода модели. Полный бенчмарк, точная скорость токенов и превосходство над 1.5B не измерялись. Тестовый код редактора удалён; веса остаются в кэше браузера.
