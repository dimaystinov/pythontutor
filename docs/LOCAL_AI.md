# Локальный помощник

С 15 октября 2026 в приложении оставлена **Qwen2.5-Coder-7B-Instruct-q4f16_1-MLC**. Coder 0.5B, Coder 1.5B и Qwen3 1.7B удалены из доступных вариантов по результатам проверки учебных ответов и по просьбе владельца. Старая настройка выбора автоматически переключается на 7B. Нет автоматического перехода на слабую модель или облако.

Модель исполняется локально через WebLLM/WebGPU, требуется shader-f16 и достаточно памяти GPU. Ориентир первой загрузки — 4–4,5 ГБ; в проведённой проверке загрузка и инициализация заняли 152 секунды, повторная инициализация из кеша — 5 секунд. Восемь проверенных ответов 7B заняли 8–20 секунд каждый на текущем компьютере. Это не обещание такой же скорости на другом устройстве.

## Что модель видит

Название и условие текущей задачи, описание учебной среды, включённый код редактора, несколько последних реплик беседы. У всех 148 страниц задач есть отдельный блок материала: меню не подмешивается вместо условия. Лимит условия увеличен до 3200 символов, чтобы полностью передавать длинную задачу «Ударения». Код ограничен первыми 900 символами; при обрезке модель явно получает уведомление о неполном фрагменте. Для Python 3 добавлена проверенная справка по input/int, /, //, % и range.

До успешной сдачи готовые fenced-блоки программ скрываются. Это не строгая защита от смысловых спойлеров и не гарантия правильности объяснений. 7B показала лучший результат среди проверенных вариантов, но тоже допускала неточные формулировки. Проверенные подсказки учебника и тесты остаются опорой для ученика.

## Проверки

Сравнены четыре модели, 20 ответов в исходном режиме и 12 ответов на других задачах со справкой Python 3. Дополнительно проверен настоящий интерфейс с текущим кодом и полным контекстом обучения. Подробный разбор и исходные ответы: [аудит](audit/LOCAL_AI_EVALUATION_20261015.md). Результаты являются ограниченной практической проверкой, а не статистическим бенчмарком всех тем Python.

## Без интернета и смена ученика

Курс скачивается на странице PWA; модель и Whisper загружаются отдельно при первом использовании. После загрузки они работают на устройстве. Для озвучки требуется локальный русский системный голос. Микрофон включается действием пользователя; облачного резервного распознавания нет.

В «Настройки → Начать обучение заново» удаляются решения, отметки, черновики и переписка текущего профиля. Скачанный курс и веса моделей остаются. Устаревшие вкладки не могут записать старый результат после сброса. [Проверка без сервера](audit/OFFLINE_RESET_20261014.md).

Модель: https://huggingface.co/Qwen/Qwen2.5-Coder-7B-Instruct . Браузерный runtime: https://github.com/mlc-ai/web-llm . Пересборка локальных библиотек: `sh scripts/browser-ai/build.sh`.

Предыдущие наблюдения сохранены в [историческом отчёте](audit/LOCAL_AI_20260927.md).

## Подготовка из GitHub Release

Начиная с v1.1.0, пользователь получает модель только через GitHub:

1. Откройте помощника или «Настройки → Подготовить ИИ», нажмите «Скачать с GitHub». Если браузер ограничил несколько загрузок, воспользуйтесь ссылками на три отдельные части.
2. Нажмите «Выбрать скачанные пакеты» и выберите все три `.tar` файла. Распаковывать их не нужно. Проверка SHA-256, сохранение и запуск выполняются автоматически.

Пакеты можно импортировать по одному, передать на флешке или сохранить для всего класса. Для голосового ввода предусмотрен отдельный пакет Whisper. Архив курса включает Python/Pyodide, OpenCV, визуализатор, формулы, WebLLM и Transformers/ONNX Runtime. Системный голос для озвучки ответов предоставляет ОС; он не входит в релиз.

GitHub Release запрещает межсайтовое чтение файлов JavaScript через CORS. Поэтому сайт открывает обычные ссылки скачивания и просит один раз выбрать полученные файлы. Веса не запрашиваются с Hugging Face, внешние прокси не используются. После импорта модель хранится в Cache Storage этого сайта. Очистка прогресса ученика её сохраняет; полная очистка данных браузера удаляет. Для начальной загрузки и хранения потребуется место как для скачанных пакетов, так и для кэша; после успешного импорта скачанные пакеты можно перенести на внешний носитель.

Проверенные версии и SHA-256 перечислены в `scripts/offline/assets.lock.json`. Общий размер файлов модели и распознавания речи — 4 341 990 296 байт. Пакеты собираются GitHub Actions; исходные загрузки с upstream выполняет только издатель релиза. Лицензии моделей: Qwen2.5-Coder — Apache 2.0, Whisper — MIT; тексты лежат в `docs/licenses/`.

### Изменения загрузчика WebLLM

В vendored `webllm.mjs` внесены два локальных исправления: суффикс `resolve/main/` добавляется только для Hugging Face; WASM на localhost читается через тот же кэш, что и на HTTPS. Импортёр сопоставляет идентичный `ndarray-cache.json` с именем `tensor-cache.json`, которое использует эта версия WebLLM.
