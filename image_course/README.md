# Обработка изображений

Восемь новых заданий: оттенки серого, негатив, масштабирование, поворот,
пороговая обработка, размытие, Canny и центральный фрагмент.
Для каждого задания заданы три различных входных PNG, включая нечётные размеры.
Проверка использует фиксированные входы из каталога, а не загруженное учеником изображение.

Программа читает `input.png` и сохраняет `output.png` в изолированном рабочем
каталоге одноразового контейнера. OpenCV работает без оконного интерфейса;
результат показывается в браузере. Исходные фотографии пользователя не сохраняются
на сервере после выполнения. Прогресс и исходный код решений сохраняются в базе.

`catalog.json` — метаданные задач, стартовый код, эталонные программы и перечень
проверок. `fixtures/` — процедурные входные изображения, `expected/` — эталонные
результаты. Эти файлы не относятся к архивному курсу: созданы для данного проекта
и распространяются по MIT. Эталонные программы не исполняются веб-сервером.

Для воспроизведения ресурсов установите зависимости из `runner/requirements.lock`
и запустите `python scripts/generate_image_course.py`. Версии генератора и SHA-256
изображений записаны в `manifest.json`. После изменения версии OpenCV проверьте
эталоны в контейнере; не регенерируйте их при старте сервера.
