Питонтьютор без интернета

Скачайте весь курс один раз: 15 уроков, 134 задачи, 14 заданий OpenCV, тесты и среду Python. После загрузки можно закрыть браузер и продолжить без работающего сервера.

Проверка полностью выполняется на устройстве. Решения, черновики и история помощника хранятся только в этом браузере. Qwen и Whisper подготавливаются один раз из пакетов GitHub в помощнике или настройках. Все учебные функции работают на устройстве. Учётная запись не нужна.

Проверяем доступность офлайн-режима…

Для установки используйте кнопку установки в браузере. На iPhone/iPad: «Поделиться» → «На экран Домой». Для размещения на сервере нужен HTTPS; на этом компьютере подходит localhost.

Локальный прогресс

Очистка данных сайта удаляет локальные решения и скачанный курс. Сохраните резервную копию перед очисткой или сменой устройства.

Локальный помощник

Qwen Coder 7B работает на устройстве с WebGPU и достаточной памятью. Подготовьте модель один раз; пакеты можно передать другим ученикам на флешке.

За этим компьютером будет заниматься другой ученик? Можно начать обучение с чистого листа.

Очистить прогресс на этом устройстве?

Будут удалены решения, отметки в меню, черновики Python и OpenCV, переписка с помощником в текущем локальном профиле. Отменить очистку можно только восстановлением резервной копии.

Курс, среда Python и скачанные модели останутся на устройстве. Открытые вкладки учебника перезагрузятся.

Чтобы сохранить работу, сначала нажмите «Скачать резервную копию данных» выше.
