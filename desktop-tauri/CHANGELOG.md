# Версии PythonTutor

Номера версий: MAJOR.MINOR.PATCH. MINOR — новые возможности, PATCH — исправления. Одна версия имеет одинаковый номер на Windows и macOS Apple Silicon. Опубликованные установщики не заменяются: исправления получают новый номер.

## 2.4.0

- Вход по фамилии, имени, классу и PIN-коду из четырёх цифр.
- Регистр букв и случайная английская раскладка русского имени не мешают входу.
- Старый профиль переводится на новые данные входа с сохранением прогресса.
- Автоматический выход после 10 минут без нажатий, ввода или прокрутки. После сна компьютера срок сеанса проверяется повторно. Решения и черновики сохраняются.

## 2.3.3

- Выпуск для Windows x64 и macOS Apple Silicon. Сборки macOS Intel прекращены.

- Черновики задач изолированы по локальным профилям. Общие черновики старых версий больше не подставляются ученикам.
- Очистка прогресса удаляет решения, черновики и переписку текущего ученика; данные других профилей и скачанные компоненты остаются.
- Отметки задач обновляются из текущего прогресса, без сохранения старого зелёного фона.
- Работа с базой решений приложения больше не зависит от текстовых подстановок при сборке.

## 2.3.2

- Отмена ответа при переключении модели; сохранение выбранной модели OpenCode.
- Подсказки и контекст текущей задачи, общая переписка без старых подсказок.
- Переписка видна во время голосового разговора.
- Автоматическая установка CLI и голосового ввода, прогресс загрузки.
- Ограничение времени инициализации Qwen; явные ошибки провайдера 403/429.

## 2.3.1

- Меню работает и при недоступности jQuery; добавлена проверка для сборок Windows и macOS.

- Убрано прикрепление изображений к сообщениям помощника. Текстовый и голосовой ввод сохранены.

## 2.3.0
- Расшифровка речи через LocalSpeech SDK, без старого резервного Whisper и отправки записи на сервер.
- Голосовой SDK обновляется отдельно: каталог совместимых версий, установка с проверкой файлов и возврат к уже установленной версии.
- Неудачная загрузка SDK сохраняет работающую версию.

## 2.2.0
- Кнопка меню работает независимо от повторной отрисовки заголовка теории.
- Обновление из настроек: фоновое скачивание с проверкой SHA-256, установка и перезапуск без страницы GitHub и ручного переноса приложения.
- Windows использует режим установки с прогрессом без вопросов; macOS сохраняет прежнее приложение для восстановления.
- Прямые ссылки на последний готовый установщик; запасной адрес загрузки через GitHub API.

## 2.1.3
- Общая переписка Питоныча между задачами, перенос старых диалогов и очистка переписки отдельно от учебного прогресса.
- Более заметные определения в теории.

## 2.1.2
- Панель Питоныча закрывается кнопкой-крестиком; переписка сохраняется.
- Более крупный и контрастный текст условий, увеличенные интервалы и отдельный заголовок.
- В установленном приложении убран блок повторного скачивания курса: учебник уже входит в сборку.

## 2.1.1
- Компактный установщик Windows: вместо полного WebView2 включён небольшой загрузчик. Уже установленный WebView2 используется повторно; при его отсутствии нужен интернет, ход установки отображается.
- Удалён старый экран выбора пакетов: Qwen 7B скачивается непосредственно по кнопке, с прогрессом, отменой и повторной попыткой.
- Голосовой ввод устанавливается по одной кнопке; панель загрузки видна в настройках, даже если окно помощника закрыто.
- Папки и файлы выбираются автоматически; встроенный консультант по-прежнему не требует загрузок.

## 2.1.0
- Встроенный консультант по правилам включён по умолчанию, в том числе при переходе со старых настроек. Не требует моделей и интернета.
- Объяснения типичных ошибок Python, конкретных непройденных тестов и ссылки на теорию.
- Настройки показывают установленную и последнюю полностью опубликованную стабильную версию для этой системы.
- Проверка обновлений, скачивание установщика с прогрессом, отмена и проверка SHA-256 из GitHub Release. После загрузки открывается стандартный установщик; на macOS пользователь заменяет приложение в «Программах».
- Профили и прогресс не удаляются при обновлении.
- Прогресс загрузок LocalSpeech, модели и курса обновляется во время получения данных.
- Модели и голосовой модуль устанавливаются отдельно и могут быть удалены из настроек.
