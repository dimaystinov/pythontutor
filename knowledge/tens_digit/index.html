Число десятков

Вы решили задачу. Теперь можно сравнить подходы.

Убираем единицы, затем берём последнюю оставшуюся цифру.

Авторский разбор для локальной версии на основе условия задачи. Это не выгрузка чужих посылок и не официальное решение исходного сайта.

Ваше принятое решение

Рекомендуемое решение: Рекомендуемый подход

Деление на 10 убирает единицы, остаток по 10 выделяет десятки.

n = int(input())
print(n // 10 % 10)

Время: O(d) на чтение d цифр; арифметика зависит от размера числа. Память: O(d) для записи числа.

Другой способ: Другой способ

Дополняем запись слева нулём до двух символов и читаем предпоследнюю цифру.

s = input().strip().zfill(2)
print(int(s[-2]))

Время: O(d) на чтение d цифр; арифметика зависит от размера числа. Память: O(d) для записи числа.

На что обратить внимание

  • Нужно получить цифру десятков, а не количество полных десятков.
  • У однозначного числа цифра десятков равна 0.

Рекомендация учитывает сложность и читаемость для этой задачи. Единственного самого быстрого решения для всех размеров входа и всех компьютеров может не быть.
