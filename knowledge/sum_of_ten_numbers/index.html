Сумма десяти чисел

Вы решили задачу. Теперь можно сравнить подходы.

Читаем десять чисел и складываем их.

Авторский разбор для локальной версии на основе условия задачи. Это не выгрузка чужих посылок и не официальное решение исходного сайта.

Ваше принятое решение

Рекомендуемое решение: Сумма генератора

sum суммирует значения генератора без сохранения списка. Внешний именованный накопитель не нужен.

print(sum(int(input()) for _ in range(10)))

Время: O(10), то есть O(1). Память: O(1).

Другой способ: Явный накопитель

Явный цикл показывает изменение суммы после каждого слагаемого и использует лишь накопитель и счётчик.

total = 0
for _ in range(10):
    total += int(input())
print(total)

Время: O(10), то есть O(1). Память: O(1).

На что обратить внимание

  • Нужно считать ровно десять чисел.
  • Строки input нужно преобразовать в int.

Рекомендация учитывает сложность и читаемость для этой задачи. Единственного самого быстрого решения для всех размеров входа и всех компьютеров может не быть.
