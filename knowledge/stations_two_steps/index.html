Рекомендуемое решение: Решение

Считайте только впервые достигнутые вершины второго слоя, не все маршруты длины два.

n, m = map(int, input().split())
g = [[] for _ in range(n)]
for _ in range(m):
    a, b = map(int, input().split())
    g[a-1].append(b-1)
    g[b-1].append(a-1)
from collections import deque
s = int(input()) - 1
dist = [-1] * n
dist[s] = 0
queue = deque([s])
while queue:
    v = queue.popleft()
    for u in g[v]:
        if dist[u] == -1:
            dist[u] = dist[v] + 1
            queue.append(u)
print(dist.count(2))

Время: O(n + m). Память: O(n + m).

Другой способ: Обход слоями

Следующий список содержит только новые вершины, удалённые ещё на одно ребро.

n, m = map(int, input().split())
g = [[] for _ in range(n)]
for _ in range(m):
    a, b = map(int, input().split())
    g[a-1].append(b-1)
    g[b-1].append(a-1)
s = int(input()) - 1
dist = [-1] * n
dist[s] = 0
layer = [s]
while layer:
    following = []
    for v in layer:
        for u in g[v]:
            if dist[u] == -1:
                dist[u] = dist[v] + 1
                following.append(u)
    layer = following
print(dist.count(2))

Время: O(n + m). Память: O(n + m).
